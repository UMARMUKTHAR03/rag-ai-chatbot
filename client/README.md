# OmniMind AI — Legacy Streamlit Client

> **Note**: OmniMind AI v2.0 features a modern high-performance React 19 + TypeScript + Vite frontend located in the [`frontend/`](../frontend/) directory. This Streamlit client is maintained for reference and local experimentation.

### Running the Streamlit Client
```bash
# Ensure backend is running at http://localhost:8000
pip install streamlit requests
streamlit run app.py
```
